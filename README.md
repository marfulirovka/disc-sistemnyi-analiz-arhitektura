# Системный анализ и моделирование архитектуры предприятия

Материалы дисциплины магистратуры РГСУ: направление 38.04.05 «Бизнес-информатика», профиль «Бизнес-аналитика», 1 курс, 2026/2027 учебный год. Очная (БИЗ-М-2-Д-2026-1) и заочная (БИЗ-М-2-З-2026-1) формы.

Преподаватель — М. Г. Заводчикова, кафедра экономики, финансов и капитала, факультет экономики и управления.

## О дисциплине

Два семестра. В первом — системный анализ: как видеть организацию как систему, разбираться в запутанных проблемах, строить модели и обосновывать решения. Во втором — архитектура предприятия (TOGAF, ArchiMate). Все задания первого семестра выполняются на одном объекте — организации, которую студент знает по опыту, или учебном кейсе.
